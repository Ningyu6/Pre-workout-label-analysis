# Pre-workout Ingredients and Label Transparency

# Overview
Analysis of Ingredient patterns and dosage disclosure in pre-workout supplement labels

# Project Files
## Raw data

Original files obtained from the NIH Dietary Supplement Label Database (DSLD)

`ProductOverview.csv`: Product-level characteristics and identifiers

`DietarySupplementFacts.csv`: Ingredient, serving-size, and dosage records

`LabelStatements.csv`: Statements and claims reported on product labels

## Rstudio Cleaning and Analysis

`Preworkout_label_analysis.R`: data cleaning and statistical analysis

## Cleaned Analytical Data

Datasets generated by the R analysis and used as inputs for Tableau. Files listed below:

`Preworkout_label_metrics.csv`:label-level analytical dataset

`Preworkout_label_ingredients.csv`: ingredients-level analytical dataset
