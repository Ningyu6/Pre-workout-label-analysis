# Pre-workout Ingredients and Label Transparency
# Overview
Analysis of Ingredient patterns and dosage disclosure in pre-workout supplement labels

# Data Source
NIH Dietary Supplement Label Database (DSLD)

# Files
-`Preworkout_label_analysis.R`: data cleaning and statistical analysis

-`Preworkout_label_metrics.csv`:label-level analytical dataset

-`Preworkout_label_ingredients.csv`: ingredients-level analytical dataset
